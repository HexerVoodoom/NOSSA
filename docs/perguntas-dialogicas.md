# Perguntas Dialógicas

Lista completa das **perguntas dialógicas** (fluxo de Avaliação Dialógica, `evaluationType: "dialogica"`) usadas na Arquitetura de Carreira. Cada pergunta está vinculada a uma competência e categoria, e carrega as mesmas tags de cargo (`associado`/`liderança`) da competência de origem — são essas tags que o sistema usa para filtrar quais perguntas aparecem para cada cargo durante o fluxo de avaliação.
